# Design system — Les Fils à Maman

Page statique en HTML et CSS (sans JavaScript ni framework) regroupant les composants du site click & collect « Les Fils à Maman ».

- `index.html` : la page du design system
- `system.css` : variables de couleurs en deux niveaux (`--primitive-*` pour les valeurs, `--semantic-*` pour les rôles), composants en couches `@layer`, classes en BEM, tailles en rem
- `system-demo.css` : mise en page de la page de démonstration
- `assets/` : polices et visuels

Maquettes : https://www.figma.com/design/e8BqdgVoRoGSz7QAoYilwo?node-id=19-488
